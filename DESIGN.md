# Home Assistant visual conventions

Inherit the installed HA theme and font. Operate mode: camera selection, current
connection/source status, live camera tiles, then searchable event history and
timestamp playback. Configuration belongs to native config/options flows.
Use semantic buttons, labels, visible keyboard focus, responsive grids and HA
theme variables. Empty/error/loading states explain the next useful action.
No external fonts, scripts, analytics or image CDNs.
